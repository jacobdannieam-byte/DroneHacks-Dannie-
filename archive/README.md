# Archive

This folder holds code that we do not use. Nothing in the repository imports it or runs it. We keep
it only for reference.

| Folder | What it is |
|---|---|
| `organizers_starter_package/` | The starter project that the organizers gave to each team (`onboard/`, `refnav/`, `main.py`, the notebook and their files). Our drone code does not use it. Its own README is in that folder. |
| `dannie_computer_setup/` | Dannie's notes on how to set up a computer and a walk-through of the starter code. |
| `old_scripts/` | Scripts that a newer script replaced. `smoke_flights_install_on_drone_16.sh` was replaced by `drone_code/install_on_drone_16.sh`, which installs both of our packages. |

Soham's `team_nav` is not in this branch. It is on the `main` and `soham-stages` branches. On the
drone, it is in `~/archive/20261107_cleanup/soham_team_nav`.
